# SparkAuto VRTS

Vehicle Repair Tracking System demo (SDP152, Group Eagles).

## Run it
Open `index.html` in a browser, or in VS Code install the Live Server extension, right-click `index.html` and choose Open with Live Server.

## Files
- `index.html`: login screen, layout, the dialog used for pop-ups
- `style.css`: colours (variables at the top), layout, print rules
- `script.js`: all logic. Sections are labelled by increment (login, jobs, parts, invoice, reports)

## Demo logins

## Reset the demo data
Data is saved in the browser (localStorage key `vrts3`). Use a private window, or clear site data, to start fresh.
